📘 Subir Cursos desde JSON

Sube el archivo 3-cursos.json que contiene la información de todos los cursos junto con sus prerrequisitos (si los hay). 

{
    "cursos": [
      {
        "codigo": "ICC1001",
        "nombre": "Introducción a la Ingeniería",
        "descripcion": "Curso de nivelación para estudiantes de primer año",
        "creditos": 10,
        "prerrequisitos": ["MAT1001", "PHY1001"]
      }
    ]
  }
Validaciones que se aplicarán:
  • ✔️ codigo y nombre son obligatorios y deben ser strings no vacíos.
  • ✔️ creditos debe ser un número entero igual o mayor a 0 (opcional, default: 0).
  • ✔️ descripcion puede estar vacía (opcional).
  • ✔️ prerrequisitos debe ser una lista de códigos válidos de otros cursos. Se ignorará si está ausente.
  • ❌ Si un código de prerrequisito no corresponde a un curso existente, se ignorará esa relación.
  • ❌ El archivo puede contener máximo 100 cursos. Si su archivo excede este límite, la carga será rechazada para prevenir problemas de rendimiento en el sistema.

🧩 Subir Secciones desde JSON

Sube el archivo 5-instancia_cursos_con_secciones.json que contiene las secciones vinculadas a instancias de curso. Cada sección puede tener evaluaciones configuradas con tópicos y sus respectivas instancias. 

{
  "secciones": [
    {
      "instancia_curso": 1,
      "id": 1,
      "profesor_id": 3,
      "evaluacion": {
        "tipo": "peso",
        "combinacion_topicos": [
          { "id": 8, "nombre": "Pruebas", "valor": 44.5 },
          { "id": 9, "nombre": "Lecturas", "valor": 34.2 }
        ],
        "topicos": {
          "topicos": {
          "8": {
              "id": 8,
              "cantidad": 3,
              "tipo": "porcentaje",
              "valores": [
                  25.0,
                  33.3,
                  41.7
              ],
              "obligatorias": [
                  true,
                  true,
                  false
              ]
          },
          "9": {
              "id": 9,
              "cantidad": 4,
              "tipo": "porcentaje",
              "valores": [
                  36.8,
                  36.8,
                  5.3,
                  21.1
              ],
              "obligatorias": [
                  true,
                  true,
                  false,
                  false
              ]
          }
        }
      }
    }
  ]
}
Validaciones aplicadas:
  • ✔️ instancia_curso, id y profesor_id son obligatorios y deben ser enteros.
  • ✔️ Si se incluye evaluacion, debe tener un tipo válido: "peso" o "porcentaje".
  • ✔️ La suma de los valores de tópicos tipo "peso" se normaliza automáticamente para calcular porcentajes relativos.
  • ✔️ Los porcentajes y valores se convierten a decimales (ej. 45% → 0.45) con 2 decimales, redondeados para sumar 1.00.
  • ❌ Se valida que las instancias de curso y profesores existan en la base de datos.
  • ❌ Se rechaza la sección si faltan tópicos o si las cantidades no coinciden con los arreglos de valores/obligatorias.
  • ❌ El archivo puede contener máximo 100 secciones. Si su archivo excede este límite, la carga será rechazada para prevenir problemas de rendimiento en el sistema.

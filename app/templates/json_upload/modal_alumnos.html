📄 Subir Alumnos desde JSON

Por favor sube el archivo 1-alumnos.json con los datos de los estudiantes.
Este archivo debe contener una estructura como: 

{
  "alumnos": [
    {
      "id": 1,
      "nombre": "Juan Pérez",
      "correo": "juan@example.com",
      "anio_ingreso": 2020
    }
  ]
}
Validaciones que se aplicarán:
  • ✔️ El campo correo debe tener un formato válido y ser único.
  • ✔️ Todos los campos deben estar presentes y tener el tipo de dato correcto (id: opcional, nombre: string, correo: string, anio_ingreso: entero).
  • ✔️ Si no se proporciona un id, se asignará automáticamente uno disponible.
  • ❌ No se permiten correos repetidos ya existentes en la base.
  • ❌ El archivo puede contener máximo 100 alumnos. Si su archivo excede este límite, la carga será rechazada para prevenir problemas de rendimiento en el sistema.

👨‍🏫 Subir Profesores desde JSON

Por favor sube el archivo 2-profesores.json con los datos de los profesores. Este archivo debe tener una estructura como: 

{
    "profesores": [
      {
        "id": 1,
        "nombre": "Ana Torres",
        "correo": "ana@example.com"
      }
    ]
  }
Validaciones que se aplicarán:
  • ✔️ El campo correo debe tener un formato válido y no repetirse.
  • ✔️ Todos los campos son requeridos: nombre (string), correo (string).
  • ✔️ Si no se proporciona id, se asignará automáticamente uno disponible.
  • ❌ Correos duplicados provocarán error de carga.
  • ❌ El archivo puede contener máximo 100 profesores. Si su archivo excede este límite, la carga será rechazada para prevenir problemas de rendimiento en el sistema.

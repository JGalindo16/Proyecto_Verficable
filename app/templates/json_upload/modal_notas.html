📝 Subir Notas de Evaluaciones

Sube el archivo 7-notas_alumnos.json que contiene las notas asignadas a cada alumno por evaluación. Debe tener la siguiente estructura: 

{
    "notas": [
      {
        "student_id": 15,
        "instance_eval_id": 2304,
        "grade": 6.2
      }
    ]
  }
Validaciones aplicadas:
  • ✔️ student_id, instance_eval_id y grade son obligatorios.
  • ✔️ grade debe ser un número entre 1.0 y 7.0.
  • ❌ Se verifica que el student_id y instance_eval_id existan en la base de datos.
  • ❌ El archivo puede contener máximo 100 notas. Si su archivo excede este límite, la carga será rechazada para prevenir problemas de rendimiento en el sistema.
  • ℹ️ Se actualiza la nota si ya existe, o se inserta si no existe previamente.
